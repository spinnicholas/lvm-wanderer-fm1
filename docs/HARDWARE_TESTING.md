# Wanderer 0.9 hardware testing

## Author’s report

I have physically tested Wanderer 0.9 on my own M-VAVE FM-1 and successfully rolled back to another firmware. Wanderer remains a work in progress.

This report was added after the first public release documentation was prepared. It supersedes the earlier statement that no physical FM-1 test had taken place.

## Recorded scope

Physical testing on my own M-VAVE FM-1 and a successful rollback are confirmed. The starting firmware, rollback destination/version, installation tool, and detailed per-feature results have not yet been recorded. No claim is made here about testing every preset, a measured worst-case audio deadline, every flash operation, every device revision, or interrupted-update recovery.

The Firmware Hub specifically requests installation from official V15 and another custom firmware as well as leaving the firmware again. The successful rollback covers the latter; the two starting-firmware routes still need to be documented before claiming the full Hub checklist.

# Wanderer 0.4: large-symbol interface

The 240 × 240 screen is drawn as one composition through four 240 × 60 RGB565 DMA transfers. No full framebuffer is allocated. **WANDERER** is the only on-screen word; numbers appear for parameters. The home view places Anchor and Memory in two large cards. Each has a 64-pixel, antialiased original symbol inside a sixteen-position orbit. Bright nodes show captured events, and a larger open node follows the transport. The active listening mode gets an underline beneath its orbit. Layer uses a third full-width card, a large 64-pixel stack symbol, a sixteen-step rail, and a slider switch. Its knob is left when off and right when on.

Turning a parameter opens a dedicated view with a large symbol, a large number, sixteen meter beads and a broad horizontal meter. Droplet = Melt, drifting arrows = Drift, hourglass = Decay, metronome = tempo, speaker = level, nested sizes = text-size setting. A confirmation takes over the display with the action icon and separate X and check symbols; HOME cancels and SEL confirms. A short result view shows the action with a check or X. The existing audible cues and physical control meanings are unchanged.

The source icon drawings use one 24-unit geometry and thick stroke; the generator renders them into 64-pixel, four-bit antialiased masks (43,008 packed bytes for 21 symbols). The font generator includes a larger numeric size, while retaining only the letters needed for WANDERER. The generated symbols are original; Lucide's ISC-licensed set was researched as an available reference, but no external icon asset is embedded. See `WANDERER_UI_0.3.md` for the full symbol key and design references.

The instrument has no touch targets; its physical buttons and encoders drive the display. Because some transformation symbols have to be learned, the companion symbol key is part of this source package. Audible cues do not yet announce parameter values or icon meanings.

Host framebuffer captures were checked at native resolution and 2× enlargement for home, parameter, confirmation, notice, light palette and switch states. The event-memory sanitizer test and scripted host scenarios passed. The 0.4 source was not cross-compiled or flashed because the pinned JieLi toolchain and AC79 SDK were unavailable in this session. The earlier 0.1 firmware binary does not contain this interface.

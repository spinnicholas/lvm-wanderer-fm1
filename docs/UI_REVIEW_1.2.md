# Wanderer 1.2 visual and product review

The 1.1 RC2 nautical Anchor and licensed Lucide/Tabler icon family remain. This pass uses four additional actual Lucide SVGs: file-plus (fresh untitled session), file-pen-line (unsaved edits), file-check (saved project/reference or valid stored project) and volume-x (digital mute). Context separates Home project status from slot validity in confirmations. File-minus means no valid Wanderer project; file-cross means an unverified result. Neither implies another firmware's data is safe to erase.

Home now reserves a bottom status strip. The slot number belongs to the successfully loaded/saved project, not whichever slot is being browsed. Loop length stays visible rather than requiring a trip to Music. Digital mute explains a common silent-instrument condition. Symbols carry the information independently of hue. Dark and light Zoom versions retain the same ordering.

The Layer icon initially overflowed its shortened card in the first candidate screenshot. The final normal view uses a 48px glyph within a 47px card with source-mask padding; Zoom uses a 24px glyph in its compact strip. Timeline rows have their own space, above the footer. Main cards, listening frames, lock, headphones, record dots and transport remain distinct.

Save/Load confirmations retain large destination numbers and explicit cancel/confirm targets. Two small symbols communicate destination validity and the current session's edited state. Persistent outcomes/errors also get a separate LED scene: SEL/SCL acknowledgment, dim HOME/FX alternatives and a SEQ/ARP storage-context lamp where applicable. Real playing/recording/key gates remain visible; hidden Home states and octave lamps do not leak through. Success uses a large destination tile and check and persists for deliberate acknowledgment. A partial project/preferences result uses two separate cards rather than showing a blanket failure.

The gallery contains 66 renderer captures, including every major menu and selected/detail/confirmation/error state, both startup themes, both UI themes, Zoom, scope states, one/two-bar timelines, chord durations and the new project outcomes. The review preserves function rather than adding decorative illustration. The approved splash and actual source SVG geometry are unchanged.

Physical review still needs to establish small-symbol readability, glare, brightness and encoder feel on the FM-1. Prefer Zoom where needed. The footer is a status aid; it does not replace large persistent outcome screens or the accessible guide.
